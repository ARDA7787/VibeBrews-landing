# VibeBrews Landing Page

Official landing page and blog for VibeBrews - AI-powered game creation platform.

## 🚀 Overview

This repository contains the landing page, blog articles, and React application for VibeBrews. VibeBrews helps creators turn their ideas into mobile games without coding.

## 📁 Project Structure

```
vibebrews-landing/
├── index.html                              # Main landing page
├── assets/                                 # Images, logos, and visual assets
├── screenshots/                            # Game screenshots and demos
├── vibebrews-react/                       # React application (development)
│   └── vibebrews-react-clean/            # Clean React build
│       ├── src/                          # React source files
│       ├── public/                       # Public assets
│       └── package.json                  # Dependencies
└── Blog Pages:
    ├── how-to-make-a-game-without-coding.html
    ├── i-have-a-game-idea.html
    ├── our-vision.html
    ├── productive-things-to-do-on-phone.html
    ├── the-3am-scroll.html
    ├── the-creative-block-is-a-lie.html
    ├── the-death-of-coding.html
    ├── the-game-you-will-never-make.html
    ├── why-i-stopped-learning-unity.html
    └── why-your-ideas-die-in-your-notes-app.html
```

## 🎯 Features

- **Landing Page**: Modern, responsive design showcasing VibeBrews platform
- **Blog Articles**: In-depth articles about game creation, creativity, and AI
- **React App**: Interactive tools and features for users
- **SEO Optimized**: Meta tags, Open Graph, and structured data
- **Mobile Responsive**: Works seamlessly on all devices

## 🛠️ Technologies

- **HTML5**: Semantic markup for blog pages
- **React**: Interactive application (Vite + React Router)
- **Tailwind CSS**: Utility-first styling
- **JavaScript**: Dynamic functionality

## 📦 React Application Setup

```bash
cd vibebrews-react/vibebrews-react-clean
npm install
npm run dev
```
